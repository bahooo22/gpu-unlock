# Локальный контекст анлока

Upstream: `https://github.com/Zagitta/gpu-unlock` (v2.0.0, GPL-2.0, модуль для Linux).
Здесь — исходники форка и рядом, в проекте, — подготовленный USB-корень для Windows-машины:
`..\artifacts\unlock\usbroot-ga102` (81 МБ, SHA256SUMS внутри).

## Что это даёт

Анлок открывает FP16/BF16-тензорные ядра GeForce `10de:2489` (GA104, RTX 3060 Ti); VRAM не
добавляется. Для LLM выигрыша нет — там FP32-путь, — но для диффузии и обучения ядра полезны.

## Риски

- EFI-загрузка с модифицированным GSP-модулем; Secure Boot должен быть выключен;
- к Blackwell (RTX 50) неприменимо; на ноутбучных вариантах может не завестись;
- перед первым запуском снимайте дампы и держите штатный EFI под рукой.

Подробности — `..\harness\docs\unlock.md` и `..\harness\docs\unlock-code-analysis.md`.
